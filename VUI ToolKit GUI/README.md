# VUI ToolKit (desktop GUI)

Настольное приложение для работы с аудио: обработка эффектами, VAD,
диаризация, склейка, TTS (ElevenLabs / OmniVoice), поиск слов, метаданные.

Интерфейс — Flet (тёмная/светлая тема в стиле веб-версии). Старая
tkinter-версия сохранена в `_backup_tkinter_gui/` и в запуске не участвует.

## Запуск

```bash
pip install -r requirements.txt   # при первом запуске
python main.py
```

Или двойным кликом по `Запустить VUI ToolKit.bat` (должен быть доступен
`python` из PATH; иначе отредактируйте bat, указав полный путь к python.exe).

Инструменты переключаются в левой панели. Задачи выполняются в фоне:
прогресс, лог и результаты — в правой панели страницы, файлы лежат в
`workspace/jobs/<id>/outputs`.

## TTS: имена файлов

- Столбец `filename` в таблице — точное имя файла для строки (без
  расширения; приоритет над шаблоном).
- Поле «Шаблон имён файлов» — имя для строк без `filename`; токен `{n}` —
  номер строки, например `reply_{n:03}` → `reply_001.mp3`.
- Если не задано ни то, ни другое — `tts_NNN.mp3` / `omnivoice_NNN.wav`.
- Существующие файлы не затираются (суффикс `_1`, `_2`, ...).

## TTS: формат синтеза

На странице TTS можно выбрать контейнер (MP3 / WAV (PCM) / OGG Vorbis):

- **MP3/OGG** — битрейт 32–192 кбит/с передаётся в ElevenLabs
  (mp3_22050_32 … mp3_44100_192, ogg_vorbis_128); для OmniVoice применяется
  его кодек по умолчанию.
- **WAV (PCM)** — частота дискретизации 16/24/44,1/48 кГц: ElevenLabs отдаёт
  PCM выбранной частоты, OmniVoice реземплирует с 24 кГц и сохраняет
  PCM_16.

Подробное описание всех вкладок — в README версии `VUI ToolKit Web`
(функционал ядер одинаковый).
