# VUI ToolKit

Набор инструментов для работы с аудио: обработка эффектами, детектор речи
(VAD), диаризация, склейка записей, синтез речи (ElevenLabs / OmniVoice),
поиск слов с разметкой и генерация метаданных реплик.

## Две версии

| Папка | Интерфейс | Запуск |
|-|-|-|
| `VUI ToolKit Web` | Веб-интерфейс (дизайн сайта из Lovable), открывается в браузере; сервер работает локально | `python main.py` или `Запустить VUI ToolKit.bat` внутри папки |
| `VUI ToolKit GUI` | Обычный десктопный GUI (tkinter), как раньше | `python main.py` или `Запустить VUI ToolKit.bat` внутри папки |

В корне лежит `Запустить VUI ToolKit.bat` — спрашивает, какую версию
открыть (1 — веб, 2 — десктоп).

Веб-версия: `python main.py` поднимает локальный бэкенд (порт 8000) и
фронтенд (порт 5173) и открывает браузер; остановка — закрыть окно или
Ctrl+C. Порт: `python main.py --port 7100`. Подробности — в README внутри
`VUI ToolKit Web`.

Обе версии содержат обновлённый TTS: столбец `filename` в таблице (точное
имя файла строки) и шаблон имён с токеном `{n}` — номером строки,
например `reply_{n:03}`.
