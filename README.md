# VUI ToolKit

Настольное приложение для работы с аудио: обработка эффектами, детектор речи
(VAD), диаризация, склейка записей, синтез речи (ElevenLabs / OmniVoice),
поиск слов с разметкой и генерация метаданных реплик.

## Установка

```bash
pip install -r requirements.txt
```

Опционально (для отдельных функций):

```bash
pip install tkinterdnd2         # drag-and-drop файлов прямо в окно
pip install simpleaudio         # прослушивание аудио внутри приложения
pip install omnivoice           # локальный TTS (модель k2-fsa/OmniVoice)
pip install pyrubberband        # изменение скорости без сдвига тона (нужен rubberband-cli)
pip install praat-parselmouth   # изменение высоты тона
```

## Запуск

```bash
python main.py
```

## Общие возможности интерфейса

- **Тёмная тема** — переключатель в правом верхнем углу окна.
- **Сохранение настроек**: выбранные режимы, токены и ключи (HF, ElevenLabs)
  запоминаются между запусками в файле `user_settings.json` рядом с
  программой. ВНИМАНИЕ: токены хранятся в открытом виде.
- **Прогресс-бар и кнопка «Прервать»** на каждой вкладке — длинную задачу
  можно остановить (прерывание происходит между файлами/строками).
- **Панель «Результаты»** на каждой вкладке: созданные файлы можно
  прослушать (кнопка «Прослушать») или открыть в папке.
- **Drag-and-drop**: файлы и папки можно перетаскивать мышью в поля выбора
  источника и в список склейки (нужен пакет tkinterdnd2).
- **Защита от перезаписи**: существующие файлы не затираются — к имени
  автоматически добавляется числовой суффикс (`_1`, `_2`, ...), о чём
  выводится предупреждение.

## Вкладки

### 1. Обработка аудио
- Источник: одна запись / несколько записей / папка (или перетаскивание).
- Режим «Готовый пресет»: встроенные bad_micro, ambience, bad_connection,
  voice_changer_higher, voice_changer_lower, stereo_to_mono — плюс
  **пользовательские пресеты** (помечены ★): любой пресет можно загрузить
  в конструктор («Редактировать»), сохранить свой пайплайн кнопкой
  «Сохранить как пресет» и удалить ненужный («Удалить»). Пресеты хранятся
  в `user_presets.json`.
- **Предпрослушивание**: кнопка «Подготовить» обрабатывает первый
  выбранный файл, после чего можно сравнить «▶ Оригинал» и
  «▶ После обработки».
- Режим «Свой пайплайн»: конструктор из эффектов (добавление, порядок,
  параметры). Тишина добавляется раздельно: флажки «Тишина в начале, с»
  и «Тишина в конце, с» со своими длительностями (есть и отдельные
  эффекты «Тишина в начале» / «Тишина в конце» в конструкторе).
- Параметры сохранения выбираются отдельно: формат (WAV / FLAC / OGG / MP3)
  и PCM-разрядность (PCM_16 / PCM_24 / PCM_32 / FLOAT — где применимо).
- Флажок «Сохранить исходные названия»: результат получает имя исходного
  файла (иначе добавляется постфикс «_processed»).

### 2. VAD (Silero)
- Источник: одна запись / несколько записей / папка.
- Режим: сохранять фрагменты речи или фрагменты без речи (паузы).
- Минимальная и максимальная длительность фрагментов; длинные фрагменты
  режутся на части, короткие отбрасываются.
- В выходную папку сохраняются фрагменты и таблица длительностей
  (xlsx или csv).
- При первом запуске модель Silero скачивается автоматически.

### 3. Диаризация (pyannote)
- Разделение спикеров моделью pyannote/speaker-diarization-community-1.
- Нужен токен Hugging Face с принятой лицензией модели.
- Результат — текстовый файл `<имя исходника>_dia.txt` с интервалами
  и спикерами; сохраняется в папку исходных записей, если не выбрана
  другая папка.

### 4. Склейка аудио
- Список записей с управлением порядком (вверх/вниз), добавление файлов
  или целой папки.
- Пауза между записями в секундах: 0 — прямая склейка без тишины,
  любое число — вставка тишины нужной длительности.
- Частота дискретизации результата: как у первого файла или фиксированная
  (8000–48000 Гц); формат и PCM-разрядность выбираются отдельно.

### 5. TTS
- Два движка на выбор:
  - **ElevenLabs (API)** — нужны API-ключ и Voice ID;
  - **OmniVoice (локально)** — клонирование голоса из эталонной записи
    (модель скачивается при первом запуске).
- Два режима: одна фраза или фразы из таблицы (Excel/CSV).
- Таблица: обязательный столбец `text`; для разных голосов — столбец
  `voice` (для ElevenLabs — voice_id, для OmniVoice — путь к эталонной
  записи голоса).

### 6. Поиск и разметка
- Источник: одна запись / несколько записей / папка.
- Слова и **словосочетания** для поиска добавляются кнопкой
  «Добавить слово/словосочетание» (фраза из нескольких слов ищется
  как единый фрагмент).
- Опция **«Разрешить неточное совпадение»**: находит слова, похожие на
  заданные (устойчиво к ошибкам распознавания); порог сходства задаётся
  в процентах.
- Речь распознаётся Whisper (модель выбирается: tiny/base/small/medium;
  при первом запуске скачивается).
- Количество искомых фрагментов задаётся параметром «Макс. число фрагментов».
- Файл разметки `.seg` сохраняется в ту же папку, где лежит исходная запись,
  в кодировке UTF-8 (с BOM — кириллица корректно читается в Wave Assistant).
- На каждый найденный фрагмент — ДВЕ метки: начало (со словом) и конец
  (пустая).
- ВНИМАНИЕ: первое число метки в .seg — номер БАЙТА в аудиопотоке
  (не отсчёта): byte = время × частота × байт/отсчёт × каналы.

### 7. Метаданные
Автоматическая генерация файла метаданных реплик
(`db_va_data_ai_assets_by_groups:` и ниже) из таблицы (xlsx/csv)
с параллельной нарезкой аудио по .seg-разметке.

- **Предпросмотр**: кнопка «Предпросмотр» показывает в отдельном окне,
  как первые N строк таблицы будут выглядеть в метаданных (включая
  структуру parts по разметке) — без нарезки аудио, только текст.
  Длительности берутся из заголовков аудиофайлов, если они доступны.
  Текст можно скопировать в буфер обмена.

- Таблица: столбцы `text`, `filename`, `intent` (распознаются и русские
  названия: «Текст», «Название файла», «Наименование интента»; имена
  столбцов можно переопределить в интерфейсе).
- **Голос** — флажок + произвольная строка вида `- voice_id_2101: # Maya`
  и её отступ в пробелах.
- **Интенты** — флажок группировки, шаблон `- {intent}:`, отступ. Столбец
  проверяется: при проблемах выводится предупреждение (отсутствующий
  столбец — генерация без уровня интентов; пустой интент у строки —
  строка пропускается).
- **Шаблон строки записи** с токенами `{filename}`, `{text}`,
  `{duration_s}`, `{duration_ms}`, `{n}` и настраиваемым отступом.
  Подстановка — простая замена токенов, поэтому Ansible-переменные вида
  `{{ db_va_data_s3_bucket }}` в шаблоне не трогаются.
- **Номер реплики `{n}`** — флажок + начальное значение; растёт на 1
  с каждой строкой ТАБЛИЦЫ (все части нарезанной реплики делят один номер).
- **Переменные (нарезка)**: если маркер переменной (например `cn`)
  встречается в имени файла, запись режется по .seg, лежащей рядом
  с аудио: отрывки, у которых начальная метка содержит заданный текст
  (например `subscriber_name`), вырезаются, оставшиеся куски сохраняются
  как `{имя}_1.wav`, `{имя}_2.wav..., а запись оформляется как
  `- parts:` (отступы настраиваются) с чередованием аудиофрагментов
  и строк переменных (у каждой переменной — свой шаблон строки, например
  `- { part_type: "subscriber_name" }`, и свой отступ). Куски текста
  сопоставляются фрагментам по порядку, разделяясь по обозначениям
  переменных (`{subscriber_name}`, `{subscriber_reason}` — задаются
  пользователем).

Пример результата:

```yaml
db_va_data_ai_assets_by_groups:
  - voice_id_2101: # Maya
      - default_ai_1_cn_busy:
            - parts:
                - { filename: 's3://{{ db_va_data_s3_bucket }}/rec_01_1.wav', transcription: 'Здравствуйте! Я Майя.', duration_s: 3 }
                - { part_type: "subscriber_name" }
                - { filename: 's3://{{ db_va_data_s3_bucket }}/rec_01_2.wav', transcription: 'сейчас занят. Говорите.', duration_s: 4 }
```

## Структура проекта

```
VUI_ToolKit/
├── main.py                  # точка входа
├── requirements.txt
├── core/                    # логика (без GUI)
│   ├── audio_io.py          # чтение/запись аудио, форматы и PCM
│   ├── effects.py           # эффекты, пресеты, пайплайн
│   ├── vad_silero.py        # VAD Silero (речь/паузы, таблица)
│   ├── diarization.py       # диаризация (pyannote)
│   ├── merge_audio.py       # склейка записей с паузами
│   ├── word_search.py       # поиск слов + .seg-разметка (Whisper)
│   ├── metadata_gen.py      # генератор метаданных + нарезка по .seg
│   ├── tts_elevenlabs.py    # синтез речи ElevenLabs
│   ├── tts_omnivoice.py     # локальный синтез OmniVoice
│   ├── playback.py          # предпрослушивание (simpleaudio / плеер ОС)
│   ├── presets.py           # пользовательские пресеты (user_presets.json)
│   └── settings.py          # настройки приложения (user_settings.json)
└── gui/                     # интерфейс
    ├── app.py               # главное окно, вкладки, тема, настройки
    ├── theme.py             # светлая/тёмная темы
    ├── widgets.py           # общие виджеты (источник, лог, результаты,
    │                        # прогресс с прерыванием, DnD, прокрутка)
    ├── processing_tab.py
    ├── vad_tab.py
    ├── diarization_tab.py
    ├── merge_tab.py
    ├── tts_tab.py
    ├── search_tab.py
    └── metadata_tab.py
```
